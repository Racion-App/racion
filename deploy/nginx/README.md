Конфиг хостового nginx сервера (`/etc/nginx/sites-enabled/racion`), копия для истории. Деплой его не накатывает:
менять на сервере вручную, проверять `nginx -t`, потом `systemctl reload nginx`. Резервные копии держать вне
`sites-enabled`: nginx подключает там всё подряд, и копия даёт «duplicate upstream».

Кеш страниц (04.11.2026): `/recipes` и `/recipe/<id>` на любом языке, без сессии, 2 часа, ключ — адрес со строкой
запроса и cookie страны. Нужен против ботов, перебирающих сочетания фильтров каталога (тысячи запросов в минуту).
Чтобы сбросить кеш: `sudo rm -rf /var/cache/nginx/racion/* && sudo systemctl reload nginx`.
