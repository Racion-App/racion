# Страницы возраста: «Меню ребёнка в N лет» и «Прикорм по месяцам»

Режим: Read с одной точкой действия. Аудитория: родители детей 6 месяцев – 3 лет из поиска («меню ребёнка в 1 год на неделю», «прикорм по месяцам»). Задача: понять нормы и режим именно этого возраста, увидеть пример недели и собрать свою. Ограничения: SSR-шаблоны Go (kidmenu.html, weaning.html), тексты ru/en/de через ключи, каждый возраст — свой адрес для поиска, токены Rubby, без эмодзи. Прикорм повторяет схему: месяцы вместо лет.

Сборка шла кодом, макет `.impeccable/mocks/decision/assigned.png` — образец композиции: фото тарелки — настоящие фото рецептов из базы, а пользователь сказал «Ну +- хотя бы как то так просто получше». Время приёмов у меню 1–3 лет не показываем: проверенного режима по часам в базе нет, подпись — приём.
